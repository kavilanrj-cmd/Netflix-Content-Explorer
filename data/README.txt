Dataset placement
=================

The dataset is already committed to this folder:

    data/netflix_titles.csv

If you ever need to restore it, download it from Kaggle and place it here using
the exact name above. The notebook finds the CSV automatically, so no path needs
to be edited.

Dataset : Netflix Shows (Netflix Titles Dataset)
Source  : https://www.kaggle.com/datasets/shivamb/netflixshows
Size    : 8,807 rows x 12 columns

Columns : show_id, type, title, director, cast, country, date_added,
          release_year, rating, duration, listed_in, description

The file is intentionally tracked in version control because the project is a
self-contained, reproducible deliverable.
